ViewState

Ce contenu n’est pas encore disponible dans votre langue.

Defined in: shared/view-state/src/ViewState.ts:140

How a model is looked at, not what it is (specs/design/p26-platform.md §2, §7): the elements hidden, isolated, colored; the annotations (the measures, and the types the plugins declare); the camera views; the sections. In memory, without the GPU; the model is never changed to be looked at.

The elements are named by references (ElementRef): their ids, the source key in fallback. resolve(index) finds them in the application; a reference found by its key takes the new ids, and says so.

resolve()

Section titled “resolve()”

resolve<E>(index): ViewStateResolution<E>

Defined in: shared/view-state/src/ViewState.ts:488

Finds the elements of the references in an application: by their ids, then by their source key. A reference found by its key takes the ids of the element (index.refOf), so that the next resolution finds it by them, and a source-key-fallback says so; one found nowhere stays as it is (the model may come back) with an unresolved.
