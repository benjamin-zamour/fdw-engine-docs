engine()

Section titled “engine()”

engine(value): PortHandle

Defined in: engine/engine-shader/src/graph/GraphBuilder.ts:524

Reads a value provided by the engine: camera (camera.viewport: the size of the target in pixels, and its inverse), object transform, time, the identifier of the object (object.id, a u32, 0 for none). These values live in the fixed frame and object slots, shared by every material. The lights are read with light.current and summed with light.sum (see stdLights); the environment with the environment.* functions (see stdEnvironment).

fold()

Section titled “fold()”

fold(initial, count, body, options?): PortHandle

Defined in: engine/engine-shader/src/graph/GraphBuilder.ts:605

A fold loop: state = initial, then count times state = body(state, index); returns the last state. The nodes body adds that depend on the state or the index are computed at each iteration, the others once before the loop. Unlike an unrolled loop (macro.repeat), the count can be a uniform (a u32). The state is a numeric scalar or vector, of the type of initial (or type for a literal).
