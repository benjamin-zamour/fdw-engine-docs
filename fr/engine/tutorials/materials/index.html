Lire le mesh et le matériau

Section intitulée « Lire le mesh et le matériau »

Un graphe lit trois types d’entrées :

  • les attributs du mesh, par sémantique : g.attribute('uv', BuiltinTypes.vec2f) ;
  • les valeurs du matériau : uniforms (g.uniform), textures (g.texture), samplers (g.sampler), définies par leur nom sur le matériau ;
  • les valeurs du moteur : la caméra, la transformation de l’objet, le temps (g.engine('time')).

Les nœuds les combinent. g.call(node, inputs) ajoute un nœud et renvoie sa sortie ; les nombres et les tableaux sont acceptés comme entrées constantes :

swizzle('rgb') prend des composantes d’un vecteur, comme .rgb dans un shader. Les types sont vérifiés à l’ajout de chaque nœud : connecter un vec4 là où un vec3 est attendu lève immédiatement une erreur, qui indique le nœud et le port en cause. La seule conversion implicite va d’un scalaire vers un vecteur (le tiling f32 multiplié par l’uv vec2).

État de rendu

Section intitulée « État de rendu »

Le renderState d’un matériau définit la façon dont il est dessiné :

Option Valeurs
alphaMode opaque (par défaut) ; mask : les fragments en dessous de la valeur alphaCutoff (0.5) sont rejetés ; blend : dessinés après les éléments opaques, de l’arrière vers l’avant
doubleSided Dessine les deux faces des triangles
depthTest Teste le depth buffer (true par défaut)
depthWrite Écrit dans le depth buffer (true par défaut, false pour blend)

L’alpha provient de l’entrée alpha de la surface : g.surface({ baseColor, alpha: texel.swizzle('a') }).

Variantes

Section intitulée « Variantes »

Certains choix se font mieux à la compilation : une texture qu’un matériau peut avoir ou non, ou un attribut que seuls certains meshes possèdent. Les features sélectionnent des variantes d’un programme, sans branchement dans le shader :

macro.optionalAttribute lit un attribut lorsque le mesh le possède, et une valeur de repli sinon ; macro.normalMapping perturbe la normale avec une normal map (voir Détails de surface). Le guide du material graph liste les nœuds et les macros.
