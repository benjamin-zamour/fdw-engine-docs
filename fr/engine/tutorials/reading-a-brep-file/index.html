Lire un fichier BREP

BREP est le format des formes d’OpenCascade (BRepTools::Write), et de FreeCAD dans ses fichiers : la topologie et la géométrie exactes d’une forme, sans noms, ni couleurs, ni unités. Son lecteur le lit dans le modèle pivot. Ici, deux équerres et un arbre : une équerre placée deux fois par les localisations d’un composé, lue, tessellée par le noyau géométrique dans un worker, affichée.

…

Le lecteur

Section intitulée « Le lecteur »

registerBrep enregistre le lecteur de .brep et .brp (le plugin fdw.brep) dans un registre du pivot. Il lit le format texte, dans ses trois versions. BREP n’a pas d’unités : donnez celles du fichier, sinon le lecteur suppose des millimètres et le dit.

Ce que devient un fichier

Section intitulée « Ce que devient un fichier »
  • Un solide, une coque ou une face est une ressource brep : ses faces sur leurs surfaces exactes, ses arêtes sur leurs courbes, chaînées en boucles. Chaque élément garde son numéro dans le fichier comme clé source (#12).
  • Un composé est un nœud, ses enfants des nœuds placés par leurs localisations. Une forme placée plusieurs fois est un seul B-rep, référencé par chacun de ses nœuds : l’équerre ici.
  • Les localisations à l’intérieur d’une forme (une face déplacée, une échelle) sont appliquées à sa géométrie ; les paramètres d’OpenCascade deviennent ceux du pivot.

Ce qu’il dit

Section intitulée « Ce qu’il dit »

Une forme que le pivot ne sait pas porter (une B-spline périodique, une surface décalée, un miroir) est une ligne lost, et le reste du fichier est lu ; de même pour les arêtes et les sommets hors d’une face, que le pivot ne sait pas placer. Un fichier qui n’est pas un BREP texte échoue par une PivotError.
