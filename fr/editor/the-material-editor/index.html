L'éditeur de matériaux

Un matériau se fait souvent avant la scène qui le montrera, ou pour plusieurs. L’éditeur de matériaux fait des matériaux seuls : ni niveau, ni viewport, le matériau est le document. C’est un profil de la coque (material-editor, voir Profils et vues) sur l’éditeur des material graphs de Éditer un matériau : le même canevas, les mêmes nœuds, le même code.

Le voici avec un cuivre brossé ouvert, prévisualisé sur le réducteur de Mesurer et couper sous le panorama HDR d’un studio photo. Rien n’est gardé quand on quitte la page.

Ouvrir l'éditeur dans une page à lui

1. Le profil

Section intitulée « 1. Le profil »

Le profil charge trois plugins : l’atelier, les material graphs (fdw.materialGraph) et la console. Il n’y a pas de scène : le moteur démarre sans viewport et ne dessine que les aperçus, dans des textures relues. La disposition : les matériaux au centre, leur aperçu à droite, la console en bas ; les menus File, Edit, Preview et View.

2. Les matériaux en onglets

Section intitulée « 2. Les matériaux en onglets »

Chaque matériau est un document dans un onglet, avec son propre historique : annuler dans l’un n’annule jamais dans un autre.

Commande Touche Ce qu’elle fait
File → New material Ctrl+N Un nouveau graph, une surface PBR et sa couleur
File → Open a material… Ctrl+O Un .material.json ; l’onglet du même fichier s’il est ouvert
File → Save the material Ctrl+S Le graph en JSON ; la version d’avant pour la comparaison
File → Close the material Ctrl+W Demande d’abord quand il a des changements non enregistrés
Edit → Undo, Edit → Redo Ceux du matériau montré (Ctrl+Z dans son canevas)

Un onglet montre • tant que son matériau est modifié ; la barre d’état dit son nom, s’il est modifié, et s’il est valide ou a des erreurs. Les boutons New, Open et Save de la barre du canevas ouvrent aussi des onglets.

Essayez : faites un nouveau matériau, ajoutez un nœud (Espace sur le canevas), puis revenez au cuivre : son historique est intact.

3. L’aperçu

Section intitulée « 3. L’aperçu »

Le panneau Material preview dessine le matériau montré, comme le disent ses réglages. Glissez l’image pour tourner autour de l’objet, la molette pour vous approcher.

  • Object : une sphère, un cube, un plan, ou un modèle à vous (Model…, ou Preview → Preview on a model…) : lu par la conversion, les formats qu’ouvre le viewer (glTF aujourd’hui), ses maillages visibles centrés et mis à la taille de la sphère. Un matériau se juge sur la forme réelle : un matériau qui lit les uv des maillages est refusé sur un modèle qui n’en a pas, et le dit.
  • Environment : aucun (la lumière et l’ambiante seules), un studio ou un ciel faits par le moteur, ou un panorama HDR à vous (HDR…, un fichier Radiance .hdr, équirectangulaire). Il éclaire les matériaux comme dans les scènes (Environment du moteur, préfiltré sur le GPU) ; son intensité le multiplie.
  • Background : une couleur unie, ou l’environnement lui-même.
  • Light, Light from, Light height, Ambient : la lumière directionnelle et l’ambiante uniforme.
  • Size : le côté de l’image, de 128 à 1024 pixels ; Animate joue le temps du moteur (la lave de la galerie coule).

Les réglages ne font pas partie du matériau : les changer ne le change jamais. Ils sont les mêmes pour tous les matériaux, et gardés avec la disposition. Preview → Save the preview settings… les écrit dans un fichier, les mêmes octets pour les mêmes réglages ; Open preview settings… les relit ; Reset the preview revient aux valeurs par défaut :

Un fichier nomme son modèle et son panorama sans leurs octets : ouvert dans une autre session, l’aperçu demande de les rouvrir.

4. Comparer

Section intitulée « 4. Comparer »

Preview → Compare with the saved version met à côté du matériau sa version telle qu’ouverte ou enregistrée en dernier, dans une session à elle ; la liste Compare du panneau choisit plutôt un autre matériau ouvert. Les deux images prennent les mêmes réglages : elles tournent ensemble. Changez le tint du cuivre, puis comparez : la version enregistrée garde l’ancienne couleur.

5. Importer et exporter

Section intitulée « 5. Importer et exporter »

Les matériaux entrent et sortent par la conversion (Le modèle pivot), jamais par des lecteurs à eux :

  • File → Import materials… lit un fichier d’un autre format (glTF), et ouvre chacun de ses matériaux, et chaque instance avec les valeurs de son parent, dans un onglet. Leurs valeurs deviennent les valeurs par défaut des uniforms de leur graph. Une texture n’a pas encore de place dans un matériau de l’éditeur : chacune est une ligne du rapport.
  • File → Export as glTF… écrit le matériau montré dans un .glb, sur une sphère (les outils ne montrent que ce qu’un maillage utilise). Un graph qui est le PBR de glTF est écrit comme tel ; tout autre est dégradé : gardé entier dans l’extension FDW_scene (relue par FdwEngine), approché pour les autres outils, et dit.

Chaque conversion écrit son rapport dans la console : ce qui a été perdu, dégradé ou mis par défaut, puis un résumé. Save garde le graph tel quel, sans perte.
