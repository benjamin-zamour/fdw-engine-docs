Ouvrir un modèle

Les moteurs lisent un format à eux, qu’il faut produire avant de rien voir. Le viewer ouvre directement, dans le moteur, les fichiers des formats que lit la conversion (le modèle pivot), sur le web comme sur le bureau : glTF, et STEP, BREP et les documents FreeCAD, leurs solides exacts tessellés par le noyau géométrique (Lire un fichier STEP) ; les autres formats CAO à venir.

Voici le viewer qui ouvre un pâté de maisons de 52 maillages. Son arbre est là avant sa géométrie : les pièces encore à venir sont en italique, et les plus grandes arrivent d’abord.

Ouvrir l'éditeur dans une page à lui

Ouvrir

Section intitulée « Ouvrir »

File → Open a model… (Ctrl+Maj+O) demande un fichier ; un fichier déposé sur la vue ou sur l’arbre s’ouvre aussi. L’éditeur web en ouvre un au démarrage avec ?open= et son URL :

Le viewer ouvre des modèles, pas des niveaux à éditer : New level et Open level… appartiennent à l’éditeur de jeu. Choisissez Open a model… pour consulter un modèle pris en charge.

L’ouverture se fait en quatre temps, la barre d’état disant où elle en est :

  1. La lecture : le fichier est lu en entier par le lecteur de son format et adapté pour le moteur. Un lecteur sans flux (glTF) le doit ; les autres liront pièce par pièce.
  2. La structure : les nœuds sont faits tout de suite, avec leurs noms, leurs transformations, leurs identifiants et leur visibilité. L’arbre est navigable, la caméra cadrée sur les bornes du modèle.
  3. La géométrie : pièce par pièce, les plus grandes d’abord et les masquées en dernier, quelques millisecondes par image : la vue reste fluide, et ce qui compte se montre d’abord.
  4. Le rapport : le panneau Report dit ce qui a été gardé, dégradé, remplacé par un défaut, perdu ou trouvé invalide, par qui et pourquoi. Rien ne change en silence ; la console dit combien de pertes il y a eu.

Un fichier STEP n’a pas de maillages : ses B-rep sont tessellés à leur chargement, par le noyau de base dans le moteur (EditorEnginePlatform.kernel en donne un autre, OpenCascade dans un worker). Le raffinement au zoom (une pièce tessellée plus finement quand la caméra s’approche) est à venir.

Sélectionner

Section intitulée « Sélectionner »

Un clic dans la vue sélectionne à une granularité : l’assemblage sous le modèle (par défaut), ou la pièce. Show → Select assemblies et Select parts la choisissent ; la barre d’outils a les deux. Un clic dans le seul nœud sélectionné descend d’un niveau, vers la pièce sous le pointeur : l’assemblage, puis ses sous-assemblages, puis la pièce. Select the parent (Alt+↑) remonte.

La sélection est gardée par chemin d’instance : la chaîne des identifiants des instances autour d’un nœud, puis le sien. Une pièce placée dix fois a dix chemins ; un chemin désigne la même pièce quand le modèle est relu.

Regarder

Section intitulée « Regarder »
Commande Touche Ce qu’elle fait
Hide H Masque la sélection et ce qui est dessous
Isolate Maj+H Ne montre que la sélection, le reste masqué
Isolate, the rest ghosted — Montre la sélection, le reste vu en transparence
Show all Alt+H Met fin au masquage et à l’isolation
Color the selection — Lui donne une couleur, une nouvelle à chaque fois
Remove the colors — Les couleurs du modèle à nouveau

Elles changent la façon de regarder le modèle, pas le modèle : elles sont dans l’état de visualisation, ni dans l’historique ni dans le fichier. Une pièce en fantôme ne se sélectionne pas ; une pièce masquée non plus. L’œil de l’arbre masque dans la vue lui aussi, et l’inspecteur donne à la sélection la couleur qu’on veut.

PMI et vues enregistrées

Section intitulée « PMI et vues enregistrées »

Quand le modèle ouvert porte du PMI, le panneau PMI filtre les annotations par type. Choisissez-y une vue enregistrée pour afficher ses annotations et déplacer la caméra vers le point de vue enregistré. La caméra est interprétée dans le repère de son nœud ; les vues orthographiques gardent leur hauteur dans les unités du modèle. All annotations retire le filtre d’annotations sans déplacer la caméra. Les fichiers STEP AP242 traduisent le PMI graphique pris en charge (textes et courbes) ; le rapport nomme les entités ou sémantiques PMI non prises en charge.

Le champ en haut de l’arbre cherche dans les noms : les nœuds trouvés et leurs parents sont montrés, ouverts ; Entrée les sélectionne tous. Un double clic sur un nœud, ou F, cadre la sélection.

Lire les propriétés

Section intitulée « Lire les propriétés »

L’inspecteur montre trois sources sous la transformation :

  • Du modèle : les propriétés du nœud dans son fichier (un numéro de pièce, une masse avec son unité), puis chaque extension par son espace de noms. Une extension qu’aucun plugin ne comprend est montrée brute et en lecture seule, jamais cachée : on sait qu’elle est là.
  • Calculées : le volume, l’aire, le centre de masse, la taille et les bornes, depuis les maillages, en mètres. Elles sont approchées, à la tolérance de la tessellation près, et dites telles ; un maillage qui n’est pas fermé n’a pas de volume, son centre est celui de son aire. Avec un B-rep, elles seront exactes.
  • De l’instance : le nœud du modèle, sa clé source (son identifiant dans le fichier), son occurrence, combien de fois il est placé, sa position dans le monde.

Dans le code

Section intitulée « Dans le code »

Le viewer est un profil de la coque (voir Profils et vues) : la même page parle au moteur par messages.

Le moteur lit les formats de son registre du pivot, glTF, STEP, BREP et FreeCAD par défaut : un hôte donne le sien (EditorEnginePlatform.pivot) pour en ouvrir d’autres, un lecteur écrit comme dans Écrire un lecteur.
