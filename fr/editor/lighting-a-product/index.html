Éclairer un produit

Les caméras d’une mise en scène disent d’où les images sont prises (Mettre en scène un produit). Son éclairage dit comment le produit est éclairé et ce qui l’entoure : des lumières, un environnement qui l’éclaire de toutes les directions, un fond vu derrière lui, un sol sur lequel il repose. Comme les caméras, l’éclairage est dans la mise en scène, jamais dans le modèle.

Voici de nouveau le galet, avec la mise en scène roller-lit.staging.json : le modèle fond blanc (une lumière principale et une lumière d’appoint), le panorama HDR studio.hdr comme environnement, un fond blanc, et un shadow catcher sous le galet : son ombre seule sur le blanc. Ouvrez l’onglet Lighting du dock de droite.

Ouvrir l'éditeur dans une page à lui

1. Les modèles d’éclairage

Section intitulée « 1. Les modèles d’éclairage »

Un utilisateur de catalogue n’éclaire pas un produit à partir de rien. Apply a rig… remplace l’éclairage par un modèle prêt ; on le change ensuite.

Modèle Lumières Environnement, fond, sol
Three-point Un spot chaud à l’avant gauche (la principale, son ombre), un appoint froid à droite, un contre-jour derrière Un studio atténué, un fond gris sombre, un sol sombre
Lightbox Une lumière douce d’en haut et des deux côtés, peu d’ombre Un studio, une boîte gris clair : le fond et le sol
White background Une principale et un appoint Un studio, du blanc, un shadow catcher : l’image de catalogue

Un panorama choisi comme environnement est gardé quand on applique un modèle, à l’intensité du studio du modèle. View → Apply a three-point lighting le fait depuis le menu ; Back to the default light retire l’éclairage : la vue est éclairée comme dans le viewer.

Essayez : choisissez Apply a rig… → Three-point. Le galet est maintenant éclairé par la gauche, dans un studio sombre, sur un sol sombre.

2. Les lumières

Section intitulée « 2. Les lumières »

Une lumière est placée autour du modèle, pas dans le monde : From est d’où elle vient vue du centre du modèle, en degrés autour de la verticale (0 devant, positif vers la droite, comme les cadrages des caméras) et au-dessus de l’horizon. Une lumière ponctuelle ou un spot est aussi à une Distance, en tailles du modèle (le rayon de ses bornes). Un éclairage fait pour une petite pièce éclaire un bâtiment de la même façon.

Réglage Ce qu’il fait
Kind Directional (rayons parallèles, un soleil ou une boîte à lumière lointaine), Point (d’un point, tout autour), Spot (un cône)
On Éteinte, la lumière est gardée mais n’éclaire pas
Intensity 1 : une surface face à la lumière est éclairée de toute sa couleur. Une ponctuelle ou un spot la donne au centre du modèle
Color Choisie, telle qu’affichée
Temperature En kelvins : 6500 K est blanc, 3000 K une ampoule chaude, 10000 K un ciel froid ; elle teinte la couleur
Cone Le demi-angle d’un spot, en degrés
Shadows Si elle projette des ombres

Add a light… ajoute une lumière d’un type, nommée d’après lui (Sun, Lamp, Spot, numérotée quand le nom est pris) ; sélectionnez-en une dans la liste pour la changer. Essayez : sélectionnez Key, tapez 3000 dans Temperature, Entrée : la lumière principale devient orange. Une valeur hors de ses bornes est refusée et le champ revient.

La taille d’une lumière (les ombres douces d’une grande boîte à lumière) vient avec le path tracer : les lumières de cette étape sont des points ou des rayons parallèles.

3. L’environnement

Section intitulée « 3. L’environnement »

L’environnement éclaire le produit de toutes les directions et se voit dans ses reflets :

  • Studio : une pièce gris doux, avec une grande lumière à l’avant gauche et une derrière, faite par le moteur ;
  • Sky : un ciel bleu et un soleil ;
  • Gradient : trois couleurs, le zénith, l’horizon et le sol ;
  • HDR panorama : une image Radiance .hdr, choisie par Choose… (ou View → Choose an HDR panorama…). Elle est nommée dans la mise en scène, ses octets ne le sont pas : rouverte, le panneau la redemande quand le moteur ne l’a pas. L’éditeur web la lit à côté de la mise en scène.

Intensity la multiplie. None ne laisse que les lumières.

4. Le fond et le sol

Section intitulée « 4. Le fond et le sol »

Le fond est ce que la caméra voit derrière le produit, à part de l’environnement qui l’éclaire : l’environnement lui-même, une couleur, ou transparent : la vue montre un damier, les rendus auront une couche alpha. Un fond blanc sous un environnement de studio est l’image de catalogue habituelle ; un fond transparent, un produit détouré pour une page.

Le sol est sous les bornes du modèle :

  • un plan, d’une couleur et d’une rugosité, assez large pour atteindre l’horizon : le produit repose sur un sol qui le reflète un peu ;
  • un shadow catcher : seulement l’ombre qu’il reçoit, plus sombre à mesure que la lumière est bloquée, aussi opaque que Shadow opacity. Sur un fond uni ou transparent, le produit garde son ombre et rien d’autre.

Essayez : choisissez Background → Transparent. Le galet et son ombre reposent sur le damier.

Dans le rendu path tracé (Edit → Rendering → Path traced, là où le backend trace des rayons), tout est tracé : les lumières, l’environnement, la couleur du fond, le plan du sol, l’ombre du shadow catcher, et le damier derrière un fond transparent (l’alpha des rendus enregistrés).

5. Dans le fichier de la mise en scène

Section intitulée « 5. Dans le fichier de la mise en scène »

L’éclairage est enregistré avec les caméras (File → Save the staging…), dans la version 2 de la mise en scène ; une mise en scène de version 1 s’ouvre sans éclairage.

Rien n’est réparé en silence : une lumière invalide est écartée, un environnement, un fond ou un sol invalide est remplacé par celui par défaut, et le panneau dit lequel et pourquoi.
