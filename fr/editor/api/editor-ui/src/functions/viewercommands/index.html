viewerCommands

Ce contenu n’est pas encore disponible dans votre langue.

viewerCommands(runtime): (c) => Promise<unknown>

Defined in: editor/editor-ui/src/embed.ts:27

The commands of the embedded viewer (design/p27-viewer.md, step 8), on the runtime of the shell: each one sent to the engine as the page would, and answered once done (a model opened, a selection made, the view state read). The same commands whatever the host: a frame (serveViewerApi), or a page that holds the shell itself.
