ModelPropertyGroup

Defined in: editor/editor-ui/src/protocol.ts:559

A group of the properties of the active node besides its components (specs/design/p27-viewer.md §2, the three sources): the metadata of the model by namespace, the computed ones (exact with a B-rep, approximate on the mesh), those of the instance.
