Project

Defined in: editor/project/src/Project.ts:135

A project: a folder, its manifest (fdw-project.json), the sources of its assets and, beside each, its metadata (oak.glb.meta: a GUID, the settings of its import, its dependencies). The catalog is derived from the metadata, never written by hand: refresh scans the folder again. It is mounted as a source, asset:<guid> reads the source of an asset wherever it is:

Nothing is changed in silence: what a scan finds or writes is in issues; an action refused throws a ProjectError and writes nothing. Libraries (mount) add the assets of other folders to the catalog.
