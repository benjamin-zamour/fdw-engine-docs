EmbeddedViewer

Defined in: editor/viewer-embed/src/EmbeddedViewer.ts:59

The viewer in a page (design/p27-viewer.md, step 8): the web viewer in a frame, driven by a small API of commands (open, select, frame, cut, explode, read and load the view state) and listened to by its events. Each command answers by a promise; the commands sent before the viewer is ready wait for it.
