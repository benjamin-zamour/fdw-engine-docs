@fdw/simulation-embed

The simulation viewer embedded in a page of another application (a simulation software, a report), driven by commands and events.
Product Editor
Visibility Public: Meant to be used by applications and plugins.
Domains Procedural and simulation
Dependencies None
Dependents editor-plugin-simulation
Tests test-unit (npx nx run simulation-embed:<target>, the families of the CI in Testing)
API API reference
Source editor/simulation-embed

The simulation viewer in a page of another application (the web interface of a solver, a report of results, a portal of tests): the application of apps/simulation (or labs/editor-web) in a frame, in the simulation-embedded profile (the view, its legend and the bar of its steps), driven by commands and listened to by its events. No dependency: the page loads this package only, the engine runs in the frame. Design: specs/design/p31-simulation.md, step 10 (in French). Tutorial: Embedding simulation results in the documentation.

  • EmbeddedSimulation.create(element, { src, result, backend, profile }): a frame filling the element, ?embed, ?api and ?origin= set: the viewer listens to the commands of this page only, and answers to its origin only; result opened at the start (?open=), and no sample of its own.
  • Commands, each a promise answered once the engine has drawn what it asked; those sent before the viewer is ready wait for it: open(url) and openData(name, bytes) (the results, once the first field is drawn), results(), shown(), show({ field, step, component, palette, range, scale, bands, smoothing, isoLines, isoSurfaces }), play(playing), deform({ field, factor, undeformed }) (factor: 'fit', a round factor; null undeformed), cut({ axis, at, flip }), probe(at, { field, component }) ({ node }, { cell }, 'max', 'min'), probes(), clearProbes(), derive(definitions), compare(sideBySide, { step, field }), difference(), getState() and setState(state), run(id). A refusal rejects with a SimulationError and its reason: nothing is approximated in its place.
  • What is drawn (SimulationShown): the field by its name, its quantity and unit, the step and its label, the range of the values and of the colors, the entries without a value, below and above, the notes (what the drawing does not show as the data is), the factor of the deformation, the cut, the side compared. A probe (SimulationProbe): its value written, the number as computed, its unit and its quality.
  • Events (on): ready, results, shown, time, probes, error.
  • The messages: tagged channel: 'fdw.simulation'; a command carries an id, its answer the same. The viewer side is serveSimulationApi of @fdw/editor-plugin-simulation, on any SimulationChannel.

Public API

Section titled “Public API”
Export Description
EmbeddedSimulation, SimulationEmbedOptions, SimulationError, SimulationChannel The client: the frame, its commands and its events
SimulationCommand, SimulationRequest, SimulationResponse, SimulationEvent The messages between the page and the frame
SimulationEventData, SimulationEventName, SimulationEventOf, simulationChannel The events, the tag of the messages
SimulationResults, SimulationSet, SimulationField, SimulationShown The results, what is drawn
SimulationShowOptions, SimulationProbe, SimulationProbePlace, SimulationDerived What to show, the probes, the derived fields
isSimulationMessage A message of the simulation viewer
