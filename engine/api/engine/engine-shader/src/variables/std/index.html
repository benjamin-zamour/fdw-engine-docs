std

const std: object

Defined in: engine/engine-shader/src/std/index.ts:57

The standard functions, by short name.

Arithmetic (add, sub, mul, div, min, max, abs, floor, fract, sqrt, log2, exp2, sin, cos, acos, atan2, pow, saturate, step), vectors (dot, cross, length, normalize, reflect), interpolation (mix, clamp, smoothstep, select), comparisons (less, lessEqual, greater, greaterEqual, equal, notEqual), arrays (index, arrayLength, for storage buffers), integers (remainder, bitAnd, bitOr, bitXor, shiftLeft, shiftRight), textures (textureSample, textureSampleLevel, textureSampleCube, textureSampleCubeLevel, textureLoad, textureLoadDepth), screen space derivatives (dpdx, dpdy, fwidth, fragment stage only), construction (vec2, vec3, vec4, uvec2, uvec3, uvec4, extend, convert), transforms (transform, transform3) and perFragment.
